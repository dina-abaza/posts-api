# 📄 Posts Manager with JavaScript

This project is a simple **Posts Manager App** built using HTML, CSS, and JavaScript.  
It fetches posts from the [JSONPlaceholder API](https://jsonplaceholder.typicode.com/posts), displays them on the page, and allows users to **delete**, **edit**, and **save** posts dynamically.

---

## 🚀 Features

- 📥 Fetch and display a list of posts from a fake API
- 🗑️ Delete any post with one click
- ✏️ Edit the post's content directly
- 💾 Save the edited content or ❌ cancel changes
- 🔄 Uses `PUT` and `DELETE` requests to simulate backend changes

---

## 🛠️ Technologies Used

- **HTML** – Page structure
- **JavaScript** – Data fetching, event handling, and logic
- **CSS (inline)** – Basic styling (you can separate it to a stylesheet)

---

## 🔗 API Reference

Using the free JSONPlaceholder API:  
- GET all posts: `https://jsonplaceholder.typicode.com/posts`
- DELETE a post: `https://jsonplaceholder.typicode.com/posts/{id}`
- PUT (edit) a post: `https://jsonplaceholder.typicode.com/posts/{id}`

Note: This is a fake API. Changes are **not actually saved** on the server.
